# 실행·종료 점검 및 파일 정리 — 2026-09-24

## 수정 사항

- `stop_bot.bat --check`: 괄호 블록 안에서 미리 확장되던 `%errorlevel%` 때문에
  PowerShell의 중지 상태(1)와 조회 실패(2)가 0으로 반환되던 문제를 수정했다.
  별도 라벨에서 검사 후 실제 코드를 반환하며 한국어 바로가기에도 전달된다.
- `run_bot.bat`: 상태·환경·연결 점검 및 수동 백업이 `.automod-stop-request`를
  삭제하지 않도록 했다. 유효한 무인자 시작이 환경 점검을 통과했을 때만 이전 요청을 초기화한다.
- 잘못된 실행 옵션은 Python·DB 초기화 전에 종료 코드 6으로 거부한다.
- 임시 폴더의 가짜 Python 모듈 및 PowerShell 검사기를 사용하는 Windows BAT 실행 테스트를
  추가했다. 실제 Discord 봇, 운영 DB, 외부 API 또는 실행 중인 프로세스를 사용하지 않는다.
- 봇 안의 오래된 `dashboard-site/` 복사본을 제거했다. 대시보드의 최신 소스는
  별도 `Big-Brother-Dashboard` 저장소에 유지하며 README와 `.gitignore`에 위치를 명시했다.

## 검증 근거

수정 전 격리 실행에서 종료 코드 오반환, 진단 명령의 종료 요청 삭제, 잘못된 옵션의 DB 접근을
재현했다. 수정 후 점검에서는 반환 코드 0/1/2 전달, 종료 요청 유지, 잘못된 옵션의 DB 미접근을
확인했다. 무인자 실행은 이전 요청을 지운 뒤 정상 종료 시 한 번만 실행되는지도 검사한다.

실행 명령(봇의 전용 Python 3.13 환경):

```text
python -B -m unittest discover -s tests -q
```

전체 262건 통과, 실패·건너뛰기 0건, 종료 코드 0(78.328초).
출력의 제공자 실패·전송 실패 로그는 테스트가 의도적으로 주입한 오류 시나리오다.

별도 대시보드는 `npm test`로 새 빌드 및 7개 테스트를 통과했다. 미사용 notes 예제 2개를
제거해도 로그인 화면, 비밀번호 세션, 접근 제한, 기간 조회, 제재 원장, 외부 관리봇 수집 검증이
통과했다. 이는 실제 운영 서버에 로그인하거나 실데이터 동기화를 검증한 결과는 아니다.
