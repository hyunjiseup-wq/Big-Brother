# BB봇 운영 인사이트

BB봇의 탐지 카드와 관리자 검수 결과를 집계하는 비밀번호 보호 운영 대시보드입니다.

- 월별·분기별·연간·전체 기간을 드롭다운으로 선택하는 감지, 정탐, 오탐, 미검수 현황
- 조회 연도와 월·분기를 바꿔 과거 집계를 확인하고 같은 기간 링크 공유
- 유형·채널·AI 제공자·등급·언어별 분포
- 배치 감사 커버리지와 마지막 운영 상태
- 마지막 동기화 시점을 기준으로 실시간·지연·저장 데이터 상태 구분
- 사이트 연결이 끊긴 동안 쌓인 미전송 KPI 건수 표시
- 메시지 원문, 사용자 ID, 메시지 ID를 저장하지 않는 집계 전용 구조
- D1 영속 저장과 토큰 인증 수집 API

봇이 실행 중일 때 `/api/ingest`로 최신화하며, 봇이 꺼져 있어도 마지막 저장 데이터는
외부 사이트에서 계속 확인할 수 있습니다.

## 관리자 전용 제재 인수인계

사이트 첫 화면과 `/staff` 모두 공용 관리자 비밀번호를 요구하며,
성공한 로그인은 `HttpOnly`, `Secure`, `SameSite=Strict` 쿠키로 8시간 유지됩니다. 같은 접속지에서
비밀번호를 5회 연속 틀리면 15분 동안 로그인이 제한됩니다.

- Discord 사용자명과 ID
- 경고·타임아웃·추방·차단 종류와 적용 사유
- 적용 시각, 예정 종료, 실제 해제 시각
- 적용·해제 처리자와 해제 사유
- 적용 중·해제·기간 만료 상태 검색 및 필터

비밀번호는 저장소에 커밋하지 말고 Sites의 비밀 환경변수 `STAFF_DASHBOARD_PASSWORD`에만
설정해야 합니다. KPI 집계 API `/api/dashboard`와 상세 이력 API `/api/staff/sanctions`도
인증된 세션에서만 조회할 수 있습니다.
