# BB봇 운영 인사이트

BB봇의 탐지 카드와 관리자 검수 결과를 비식별 집계하는 외부 KPI 대시보드입니다.

- 월·분기·연간 감지, 정탐, 오탐, 미검수 현황
- 유형·채널·AI 제공자·등급·언어별 분포
- 배치 감사 커버리지와 마지막 운영 상태
- 마지막 동기화 시점을 기준으로 실시간·지연·저장 데이터 상태 구분
- 사이트 연결이 끊긴 동안 쌓인 미전송 KPI 건수 표시
- 메시지 원문, 사용자 ID, 메시지 ID를 저장하지 않는 집계 전용 구조
- D1 영속 저장과 토큰 인증 수집 API

봇이 실행 중일 때 `/api/ingest`로 최신화하며, 봇이 꺼져 있어도 마지막 저장 데이터는
외부 사이트에서 계속 확인할 수 있습니다.
